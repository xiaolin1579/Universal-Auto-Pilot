# สถิติผู้ใช้ Dedbit / Bitsuse

Dedbit และ Bitsuse ใช้สถิติบัญชีชุดเดียวกัน เมื่อ username ตรงกัน ระบบอ่าน
Upload, Download, Ratio และ Bonus ครั้งเดียวต่อรอบค้นหาปกติ และรายงานเป็น `DED/BITS`
หากการอ่านครั้งแรกล้มเหลว จะยังลองอ่านจากอีกเว็บได้ในรอบเดียวกัน
การค้นหา Cross-Seed ยังคงข้ามการอ่านสถิติและงาน maintenance ตามเดิม

`stats_cache.json` และ `stats_history.json` ใช้ key `DED/BITS` ร่วมกัน
ข้อมูลเก่าที่แยกเป็น `DEDBIT` / `BITSUSE` จะรวมได้เมื่อยืนยันว่าเป็นบัญชีเดียวกัน:

- Cache เลือก snapshot ที่มียอดสะสมสูงกว่า ไม่บวกยอด Upload/Download ของสองเว็บ
- ประวัติชั่วโมงที่ซ้ำกันใช้ snapshot ล่าสุดตาม `raw_time` และเก็บชั่วโมงอื่นไว้
- ประวัติที่บันทึกยังจำกัด 744 ชั่วโมงตามเดิม
- บัญชีต่างกันหรือระบุ username ไม่ได้จะเก็บแยกไว้ เพื่อป้องกันสถิติปะปน

Telegram Stats Report / Stats Monthly Report และ Discord `!report` / `!month`
แสดงรายงานบัญชีร่วมครั้งเดียว โดยคำสั่งที่ระบุ `DEDBIT`, `BITSUSE` หรือ `DED/BITS`
อ่านชุดข้อมูลร่วมเดียวกันเมื่อข้อมูลของบัญชีนั้นรวมแล้ว

กลุ่มนี้ใช้กับสถิติผู้ใช้บนเว็บไซต์ ส่วนสถิติการรับส่งของ torrent ตาม category บน node
และข้อมูล listing, hash, zone, H&R/Quest ของแต่ละเว็บไซต์ใช้รูปแบบเดิม
