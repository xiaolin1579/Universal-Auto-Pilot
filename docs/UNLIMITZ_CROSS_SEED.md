# Cross-Seed สำหรับ Unlimitz

ระบบค้นหาในโซนที่เปิดไว้ใน `SITE[].target_urls` เท่านั้น:

| โซน | หน้า | หมวดหมู่ |
|---|---|---|
| ปกติ | `browse.php` | หมวดที่อยู่ในฟอร์มค้นหาของเว็บ |
| คลิป | `clip18x.php` | `200` |

ใช้คำค้นสำรองและค่า `SETTING.CROSS_SEED_MAX_QUERIES` ร่วมกับเว็บไซต์อื่น
ตัวกรองใช้ `selected_cats` ได้หนึ่งหมวดต่อคำค้น ส่วน `searchin` แปลงเป็น `blah`
ของเว็บ: `0` ชื่องาน, `1` รายละเอียด, `2` ทั้งหมด และส่ง `incldead` ตามที่กำหนด
รองรับค่าค้นหาที่แนบใน URL เช่น `browse.php?cat=103&blah=0&incldead=1`
ค่าจาก `search_params` ทับค่าใน URL ตามกติกาเดิม

หากไม่ระบุหมวดจะค้นหาทุกหมวดของโซนนั้น การกำหนดหลายหมวดพร้อมกัน หมวดผิดโซน
หรือเงื่อนไข Freeload/Bonus Upload/Sort/Quality ที่ยังไม่มีตัวอ่านรองรับ จะข้ามคำค้นนั้น
โดยไม่เปลี่ยนเป็นค้นหาทั้งหมด

## การยืนยันข้อมูล

1. ล็อกอินด้วย session ของเบราว์เซอร์ อ่าน CAPTCHA และรอผลตรวจจากเว็บ
   หากต้องลองภาพใหม่จะเว้นระยะ 10 วินาทีตามข้อจำกัดของหน้า login
2. ตรวจว่า URL ของผลค้นหาตรงกับโซนและ query ที่ขอ และยังเป็นหน้าสมาชิก
3. อ่าน ID ชื่อ ขนาด และสถิติจากแถวผลลัพธ์ ผูก `keyalert1` ของ `/d.php` กับ ID นั้น
4. ผ่านหน้ายืนยันเฉพาะลิงก์ `/dI.php/<ID>/...` บนโดเมน Unlimitz ที่ ID ตรงกัน
   ดาวน์โหลดเฉพาะ metainfo จำกัด 16 MiB และตรวจรูปแบบ torrent
5. อ่าน `details.php?id=<ID>&filelist=1` ที่หัวตารางเป็น `Path / Size`
   เปรียบเทียบทุกไฟล์กับ metainfo ก่อนตรวจ manifest จาก client ต้นทาง

File List ที่หายไป ว่าง หรือเปลี่ยนโครงสร้างจะถูกปฏิเสธ ยังไม่มี fallback สำหรับ
รายการที่ซ่อน File List ชื่อเรื่องหรือขนาดรวมเท่ากันอย่างเดียวไม่ถือว่าไฟล์ตรงกัน
แม้ผ่าน manifest แล้ว ยังต้อง recheck เนื้อหาก่อน seed ตาม executor เดิม

## การเพิ่มงานและ mapping

ใช้ preflight, audit, ตัวเพิ่ม tracker/งาน hash ใหม่ และ `torrent_mapping.json`
ชุดเดิม การเปิดเว็บไซต์ไม่ได้เปิดการเพิ่มงานอัตโนมัติ ต้องตั้ง
`CROSS_SEED_EXECUTION.enable_tracker_add` หรือ `enable_new_hash_add` ตามงานที่ต้องการ
ขั้นตอนเพิ่มงาน hash ใหม่ยังมีข้อจำกัดกับ rTorrent ตาม executor เดิม

ทดสอบอ่านข้อมูลจริงของสองรายการแล้ว File List ตรงกับ metainfo รวม 148 ไฟล์
และทดสอบค้นหาพบรายการที่ทราบ ID การตรวจนี้ไม่ได้เพิ่ม torrent ลง seedbox
หรือยืนยันการ recheck และ seed จริง
