# กฎจับคู่หมวดที่ตรวจจากเว็บจริง

ตรวจรายการหมวดเมื่อ 14 พฤศจิกายน 2026 เส้นทางปกติส่ง Dedbit และพิเศษส่ง Bitsuse
ไฟล์ [`auto_upload.rules.json`](../auto_upload.rules.json) มี 37 กฎ ใช้จับคู่ **ข้อความ Category** ของ BearBit แบบตรงกัน
ช่องที่อนุมานจากหมวดต้นฉบับได้จะเติมไว้ เช่น ระบบปฏิบัติการหรือประเทศของซีรีส์
ช่องที่ข้อมูลไม่พอจะเว้นว่าง และการยืนยัน checkbox ของเว็บยังเป็น `false` ทุกกฎ
กฎเปิดไว้สำหรับเตรียมงานได้ แต่การส่งจริงยังขึ้นกับ AUTO_UPLOAD และการตรวจฟอร์มสด

หมวดที่ยังไม่จับคู่ ได้แก่หมวดที่รวมหลายชนิด เช่น เกมหลายแพลตฟอร์ม การ์ตูนที่รวมหนังสือ คลิปและ AI
ต้องอ่านหมวดย่อย/ข้อมูลจริงเพิ่มก่อนเลือกหมวดปลายทาง ไม่ส่งเข้า “อื่น ๆ” อัตโนมัติ
เลข BearBit ในตารางใช้ตรวจเทียบรายการหมวดเท่านั้น runtime ยังเทียบข้อความใน Category
หากข้อความหมวดในหน้ารายละเอียดต่างจากตาราง ระบบจะรอเพิ่มกฎที่ตรงกัน

วิธีเตรียมและตรวจงานร่างอ่านได้ที่ [AUTO_UPLOAD.md](AUTO_UPLOAD.md)
